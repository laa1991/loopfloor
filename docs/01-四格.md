# loopfloor 骨架：四格 × 承载 × 形态（零角色）

> **一句话**：长程任务要治的四处坏法，各有一个归宿；**四格里没有一格是「人」或「角色」**。
> 全部读数来自一份**只读的全库普查脚本**（运行方式、样本口径与精确计数见 `README.zh.md` §4）与各条线上已落档的实测。**本文件不复制数**——同一个数两处存放必然互相腐烂。口径与盲区见 §3。

## 1. 四格

| 症状 | 承载 / 机制 | 形态 | 判据（一句可测的问句） |
|---|---|---|---|
| **上下文爆** | 压缩（`compact` + 注入面按变更频率分层 + spill 落盘） | **件** | 这条会话 messages 占比多少？压的时候丢了什么，有没有记账？ |
| **丢状态** | 接续指针（`next_write` / `next_clear`，写在盘上）+ 工作台（任务态外置的常驻面） | **件** | 换窗口后，**第一轮的输入里有没有「上次到哪了」**？ |
| **偏目标** | `goal`（会话目标）· `todo_write` + `next`（阶段进度）· `intentions` / `task-map`（跨会话软目标）+ 收口回望 | **载体 + 一个动作** | 「我为什么做这件事」来自对话历史，还是来自目标本身？ |
| **假完成** | **仪表 + 账本**（**本仓只给形状与出口条件**） | **装置** | 这次「完成」里，**哪一条证据不是这个系统自己产生的**？ |

**形态三样：件 / 载体 / 装置**——三样都是盘上的东西。这是「而不是分角色」的准确版本：不是"我们不用角色"，而是**这几格各自都有非角色的归宿**。

  ⇒ **这一格的一条最小判据形状**（可复算、实跑过）：**三态必须分得开**——「**一条编号项都没有**」/「**有条目但一栏都没写**」/「**有条目、缺某几栏**」：前两者的**修法完全不同**，合成一句就废；栏名判法用**前缀匹配**（容忍词后加注，否则「用词不同」会被读成「缺栏」= **假阳性**）；**两侧都要有**（该开火的开火、该沉默的沉默），且判据是**逐行一致**、不一致时 **exit 1** —— 不许只说「跑完了」。
  ⚠️ **同族的一条已知假阴性**（我造输入证伪出来的）：「正文里**提到**栏名」会被读成「栏**在**」——哪怕那句话是在说「这一栏我没写」。**提到 ≠ 在场**，与「引述被读成在场」是同一个形状，两侧判据里必须为它留一格。

## 4. 第四格的终点（这格不能永远「在收集数据」）

「还在收集数据」没有出口条件，会变成永久状态。**把终点写成可判定的**：

- **出口 ①（账本）**：账本里每一条都能回答「**它下一次会在什么信号上自己冒出来**」——三件门槛：**观察者**（谁 @ 什么时刻能看见它）· **还原**（至少一个位置，达标是指针）· **实测**（开过火没，没开过写 `未验`）。
- **出口 ②（仪表）**：仪表能答一句**今天答不出**的话——例如「最近 7 天，判据开火几次、误报几次」。答得出 = 数据收完；答不出 = 还没到。

**为什么先做这一格（三条一起看）**：① 它是四格里**唯一已经写出出口条件**的；② 唯一**命中过真实事故**的（降级分支被读成 `✅ started (127s)`；「校验器与被校验者同源 ⇒ 判据永远绿」）；③ 判据仍是问句的那几格里，**只有它能立刻变成装置**。

**对外写法**：这一格写「我们做到哪 + 终点是什么」，不写「我们做到了」——**把最弱的一格连终点一起摆出来，比藏起来更像尺。**

## 5. 与 AMAP 的对照（只留一句，正文不重复）

他们：三角色（Manager / Executor / Auditor）+ checkpoint / recover。
我们：**四格，零角色**。
理由不是省钱，是**状态的家数**：角色会各自长出一份任务理解（三份可能分歧的状态），所以它必须用 Manager「从目标＋已验证进度＋失败证据重建下一步」去兜——**那是用一个新角色去兜角色带来的状态分裂**。

> **加角色，是把状态分裂当机制；加结构，是把状态收敛当机制。**

## 6. 零角色的第二个理由：**可回放**（云端补，2026-09-24）

§5 那条理由是**状态的家数**（角色各自长出一份任务理解 ⇒ 得用一个新角色去兜那个分裂）。第二条更硬：**结构是数据，角色是行为** —— 数据能 diff、能重放、能复算；**行为不可复现**（同一个角色两次跑出来是两条不同的轨迹）。

⇒ 这跟事件溯源是同一件事：**状态可以从日志重放，行为不能**。所以「零角色」换来的不只是省一笔开销，而是**这一格能被外部复核**——别人拿到日志就能自己算出我们报的数，而不必先信我们的复述。（**注意这条要按证据说**：目前它是**机制上的论证**，不是一条实测读数。）
