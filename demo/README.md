# 可回放演示（replay demo）

**一句话**：同一份**只追加的事件日志**，折出来的任务状态是**纯函数**——谁跑、什么时候跑、跑几次，结果逐字相同。

```sh
node check.mjs          # 跑判据（exit code 就是判决）
node fold.mjs log.jsonl            # 全量重放
node fold.mjs log.jsonl --as-of 5  # 把世界倒回 seq 5
```

零依赖，只用 Node 内置模块。`log.jsonl` 是**合成日志**，不含任何真实系统的数据。

## 它演示什么

| # | 判据（机器可判） | 这条在说什么 |
|---|---|---|
| 1 | 同日志重放两次**逐字相同**（打印 sha256） | 状态是数据的函数，不是一次性的产物 ⇒ **可复算、可 diff、可第三方重跑** |
| 2 | `--as-of 5` 时**还没有证据**（`evidence=0`，目标仍是 active） | 世界可以倒回去看：**「当时知道什么」是可问的**，不必靠回忆 |
| 3 | 全量重放时证据到位（`evidence=1`，目标 completed） | 同一条链的两端都在日志里，谁都能自己走一遍 |
| 4 | 目标终结时**点名了一个外部物**（`endedBy` 指向 seq 6 那条证据行） | 收口条件不自产：**说「完成了」必须落在一个本系统之外的东西上** |

判据 4 是这套东西里最要紧的一条：它把「完成了」从**一句声明**变成一个**可核查的指向**。

## 它**不**演示什么（这一段请连着上面读）

- 这个演示里**没有模型**、没有 LLM、没有任何不确定性。`fold.mjs` 是一个纯函数。**所以它不能、也没有用来证明「模型输出不可复现」**——那是另一件事，需要另一套证据。
- 它量的是**可复算性的边界**，而这条边界出人意料地简单：

  > **你能从日志重算出什么，恰好等于日志里记了什么。**

  `log.jsonl` 的 seq 7 是故意放进去的例子：它记了「跑过一次命令」，但**没记「为什么跑」**。于是任何重放都拿不回来那个「为什么」——不是因为难，是因为**它不在数据里**。这条与「模型是否随机」无关，它是一条**记账**结论。
- 因此，凡是希望以后能重算的东西，就必须在**发生的那一刻**被记下来。事后补记不算，因为没有东西能为它作证。

## 与主题的关系

`loopfloor` 的第二个理由（见 README §2）说：**结构是数据（可重放），角色是行为（不可复现）**。这个演示支撑的是**前半句**——用一条能跑的判据而不是一段论证。

后半句本演示**不证**。要做那半，需要的是「同一个行为描述跑两次、结果不同」的实物；用一个确定性的替身去假装证明它，就是拿一个自己造的官当裁判——本仓不这么做。
