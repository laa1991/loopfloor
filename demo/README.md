# 可回放演示（replay demo）

**一句话**：同一份**只追加的事件日志**，折出来的任务状态是**日志的函数**——谁跑、什么时候跑、跑几次，结果逐字相同；**而这一点是被判据验过的，不是被声明的**。

```sh
node demo/check.mjs                     # 跑判据（从仓根跑；exit code 就是判决）
node demo/fold.mjs demo/log.jsonl            # 全量重放
node demo/fold.mjs demo/log.jsonl --as-of 5  # 把世界倒回 seq 5
```

零依赖，只用 Node 内置模块。`log.jsonl` 是**合成日志**，不含任何真实系统的数据。

## 判据（`node demo/check.mjs`）

**七条里两条是负对照。** 原因：有些检查**天生不会失败**——「同一份输入跑两次结果相同」，任何确定性函数都过——那种检查只能当冒烟，不能当证据。所以每条这类检查旁边都站一条**必须失败**的检查：

| # | 判据 | 这条在说什么 |
|---|---|---|
| 1 | 同日志重放两次**逐字相同**（打印 sha256） | **必要但不充分**：它挡住「每次跑结果都不一样」，挡不住「这段代码恰好没写随机数」⇒ 必须跟 [5] 一起读 |
| 2 | `--as-of 5` 时**还没有证据** | 世界可以倒回去看：「当时知道什么」是可问的，不必靠回忆 |
| 3 | 全量重放时证据到位 | 同一条链的两端都在日志里，谁都能自己走一遍 |
| 4 | 收口条件**引用了一条真实存在、且不是收口自身的记录** | 说「完成了」必须落在一条**可核查的指向**上，而不是一句声明 |
| 4-neg | 同一条检查在一份**引用了空气**的日志上（`log.no-evidence.jsonl`）**必须判否** | 负对照：判据 4 是能失败的 |
| 5 | 折法**不读日志之外的东西**（时钟 / 随机 / 环境变量 / 网络 / 性能计数） | 这才勉强够得上「状态是数据的函数」的**判别性**判据 |
| 5-neg | 同一把扫描在一份**被污染过的源码副本**上**必须开火** | 负对照：判据 5 也是能失败的 |

## 它**不**证明什么（这一段请连着上面读）

- **判据 1 只有平凡的一半。** 任何确定性函数都能过它。把「状态是数据的函数」当成由它证明的，就是把冒烟测试当证据——这正是 2026-09-25 一个外部读者读出来的缺陷；判据 [4] 的重写、以及 [4-neg] / [5-neg] 两条负对照，是对它的回应。
- **判据 4 证明的是「指向存在」，不是「那条外部物真的独立于完成者」。** 本演示里 seq 6 那条证据行是**合成日志里写下的**：它证明形状允许、且能被检查出一个外部指向，**不证明**那个指向真的由系统之外产生。要证后半句，需要一条**不产生在这个仓里**的证据。
- **判据 5 是启发式。** 它挡的是**直接写出来**的非日志输入；挡不住刻意伪装（`globalThis['Da'+'te']`），也挡不住去读**另一个文件**。
- 这个演示里**没有模型**、没有任何不确定性。`fold.mjs` 是一个纯函数。**所以它不能、也没有用来证明「模型输出不可复现」**——那是另一件事，需要另一套证据。
- 它量的是**可复算性的边界**，而这条边界出人意料地简单：

  > **你能从日志重算出什么，恰好等于日志里记了什么。**

  `log.jsonl` 的 seq 7 是故意放进去的例子：它记了「跑过一次命令」，但**没记「为什么跑」**。于是任何重放都拿不回来那个「为什么」——不是因为难，是因为**它不在数据里**。这条与「模型是否随机」无关，它是一条**记账**结论。
- 因此，凡是希望以后能重算的东西，就必须在**发生的那一刻**被记下来。事后补记不算，因为没有东西能为它作证。

## 与主题的关系

`loopfloor` 的第二个理由（见 README §2）说：**结构是数据（可重放），角色是行为（不可复现）**。这个演示支撑的是**前半句**——用一组能跑、且**每条都自带失败面**的判据，而不是一段论证。

后半句本演示**不证**。要做那半，需要的是「同一个行为描述跑两次、结果不同」的实物；用一个确定性的替身去假装证明它，就是拿一个自己造的官当裁判——本仓不这么做。
